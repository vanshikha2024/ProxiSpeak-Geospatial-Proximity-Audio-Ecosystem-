# ProxiSpeak-Geospatial-Proximity-Audio-Ecosystem-
ProxiSpeak is a real-time virtual office collaboration platform built using the MERN stack, WebRTC, Socket.io, and MongoDB Geospatial queries. It enables users to interact through proximity-based audio, where voice volume dynamically adjusts as avatars move closer to or farther from each other in a shared 2D virtual workspace.
